Add a machine

Debian, Ubuntu and Proxmox VE machines report themselves over MQTT. There's nothing to add here or in configuration.yaml — a machine appears as soon as it reports.

Checking MQTT…

1. MQTT login for your machines

Saved here and built into the install script. With the Mosquitto broker app, any Home Assistant user works (e.g. a user named vt-agent under Settings → People), or add a login in the Mosquitto broker app's configuration.

2. Install on the machine

Save the login above first.

Open a root shell on the machine (on Proxmox, the node's Shell), paste this and press Enter. It installs the agent, asks what to call the machine and whether to report every hour, and sends the first report.
